# Dotfiles de lancubal

Mi configuración personal de entorno de desarrollo.

## 🛠️ Componentes
- **Neovim**: Basado en Lazy.nvim, con soporte para Java, C/C++, Markdown y Obsidian.
- **Shell**: Fish con tema Catppuccin.
- **Prompt**: Starship con preset Catppuccin Powerline.
- **Fuentes**: MesloLGM Nerd Font.

## ⌨️ Neovim Shortcuts
Consulta el archivo `.config/nvim/PLUGINS.md` para una guía detallada de todos los atajos de teclado.
